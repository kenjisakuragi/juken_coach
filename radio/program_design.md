## レギュラー運用 SOP（Standard Operating Procedure）

### 週次スケジュール

```
月曜：翌週エピソードの「収録シート」をAIで自動生成（30分）
火曜：収録シートを2人でSlack/LINE確認・補記
水曜：ZOOM収録（40〜50分）→ 音声ファイル共有
木曜：content_pipeline.py を実行して5媒体コンテンツ生成（10分）
金曜：各プラットフォームに投稿（コンテンツ貼り付け・確認）
土曜：投稿後のコメント・反応確認 → 次回Q収集
日曜：バッファ（遅れ回収・ストック録り）
```

### 収録前チェックリスト

- [ ] 収録シート（下記テンプレート）を2人がSlackで確認済み
- [ ] ZOOMを「クラウドレコーディング」設定にしてある
- [ ] マイク・ヘッドセットの動作確認
- [ ] 静かな場所・通知OFF
- [ ] 飲み物を用意（声が出やすくなる）
- [ ] 収録時間：前後に各5分の雑談バッファを取る（冒頭の緊張解きと、自然なエンディング）
