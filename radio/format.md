# 受験ラジオ 番組フォーマット（改訂版）

## 収録スタイル

| 項目 | 内容 |
|---|---|
| 収録頻度 | 隔週1回（月2本収録） |
| 1回の収録 | 2本撮り（続けて収録） |
| 担当制 | 1本目：コーチAがメイン／からしかしが聞き手 |
|  | 2本目：からしかしがメイン／コーチAが聞き手 |
| ネタ持ち寄り | 各自が収録日までに台本を用意して持参 |
| 公開 | 週1本ペースで公開（収録から1〜2週間後） |

## メインスピーカーの役割
- テーマの設定・台本の作成
- 主論・体験談・データの提示
- まとめとリスナーへのアクション提案

## 聞き手の役割
- 「素人リスナー代表」として素朴な疑問を投げる
- 深掘りしたい箇所で「それってどういうこと？」と突っ込む
- メインの話が専門的になりすぎたときに言葉を換えて補足する
- 受験相談コーナーの質問読み上げ担当

## 台本持ち寄りルール
- 収録3日前までにLINEで共有
- 聞き手は台本を読んで「突っ込みどころ」を3つ用意する
- 台本通りに読まなくてよい（会話の自然な流れを優先）
- 収録シートのテンプレートは `radio/sheets/` を使用
