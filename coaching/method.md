# JUKEN COACH メソッド
## 顧客説明用・コアノウハウ言語化ドキュメント

---

## はじめに ― なぜほとんどの受験指導は機能しないのか

受験指導の大半は「何を勉強するか（コンテンツ）」の提供に終始しています。
参考書ルート、模試の解き方、過去問の使い方――これらは確かに必要ですが、
実はこれらだけでは成績は上がりません。

なぜか。

**「分かっているのにできない」という問題は、情報不足ではなく、心理的・行動的な問題だからです。**

勉強法を知っている生徒が全員受かるなら、YouTubeで東大生の勉強法を見た全員が合格するはずです。でも現実はそうではない。

JUKEN COACHが取り組むのは、この「分かっているのにできない」の根本解決です。

---

## JUKEN COACH メソッドの全体像

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   PILLAR 1          PILLAR 2          PILLAR 3      │
│   モチベーション    志望校戦略         実行管理       │
│   設計              設計               システム       │
│                                                     │
│   WHY を固める   → WHAT を決める  → HOW を回す      │
│                                                     │
└─────────────────────────────────────────────────────┘
              ↓ 3つが揃って初めて機能する ↓
         「自分で動き続ける受験生」の完成
```

この3本柱が揃った状態を、私たちは **「自走状態」** と呼んでいます。
自走状態に入った受験生は、コーチが何も言わなくても自分で考え、自分で計画を修正し、自分で前進し続けます。

## PILLAR 1｜モチベーション設計
### ― 潜在意識を科学的に書き換える

---

### 1-1. モチベーションの正体を理解する

多くの受験生は「やる気が出ない」ことを意志力の問題だと思っています。でもそれは間違いです。

**心理学の自己決定理論（Deci & Ryan, 1985）** によると、人間が行動を継続できるかどうかは、次の3つが満たされているかどうかで決まります。

| 欲求 | 内容 | 受験での具体例 |
|---|---|---|
| **自律性** | 自分が選んで動いている感覚 | 「親に言われたから」ではなく「自分が決めた」 |
| **有能感** | 自分にはできるという実感 | 小さな成功体験の積み重ね |
| **関係性** | 自分を理解してくれる人の存在 | コーチ・仲間との信頼関係 |

この3つが外から強制されている受験生は、監視がなくなった瞬間に動かなくなります。
逆に3つが内側から満たされている受験生は、誰も見ていなくても自分で動きます。

**JUKEN COACHがまず行うのは、この3つを意図的に設計することです。**

---

### 1-2. 「なぜその大学か」を言語化する ― WHYの深掘り

「東大に行きたい」という動機の多くは表面的です。
「親に言われたから」「なんとなくすごいから」「偏差値が高いから」という外発的動機は、プレッシャーがなくなると消えます。

コーチングの最初のセッションで必ず行うのが、**WHYの5段階掘り下げ** です。

```
Q：なぜ東大を目指すの？
A：頭がいい人が行くから

Q：なぜ頭がいい人と一緒にいたいの？
A：刺激を受けたいから

Q：どんな刺激？何をしたいの？
A：将来、社会課題を解決する仕事がしたい

Q：なぜそれが東大じゃないとできないと思うの？
A：東大のネットワークと肩書きが必要だと思う

Q：では「社会課題を解決するために東大に行く」で合ってる？
A：はい。そう考えると急に現実的になった気がする
```

この言語化プロセスを経た生徒は、自分の志望動機を**自分の言葉で**語れるようになります。
「合格したい」から「〇〇のために合格する」に変わる。この違いが、長期間の継続力を生みます。

---

### 1-3. 潜在意識の書き換え ― WOOPメソッド

「目標を紙に書いて貼る」「毎朝合格をイメージする」という方法は、実は逆効果であることが研究で示されています。

ニューヨーク大学の心理学者**ガブリエル・エッティンゲン**の研究では、「良いことだけをイメージする（ポジティブ思考）」をした受験生は、しない受験生より成績が低下することが確認されています。

代わりに有効なのが、**WOOPメソッド（Oettingen, 2014）** です。

```
W ― Wish（願望）：「東大に合格したい」
O ― Outcome（結果）：「合格したら何が得られるか？」を鮮明にイメージ
O ― Obstacle（障害）：「それを妨げる最大の内なる障害は何か？」を正直に特定
P ― Plan（計画）：「障害が起きたら、具体的に何をするか」をif-thenで設定
```

**具体例：**
```
W：英語の長文読解を毎日1題やる
O：英語が安定したら、合計点が上がって志望校が見えてくる
O：夜になると疲れてスマホを見てしまう（これが最大の障害）
P：もし夜にスマホを触りそうになったら、すぐに机の引き出しにしまい
   代わりに単語帳を10分だけ開く
```

このif-thenプランニングは、ルートダースとゴルウィッツァーの研究で「目標達成率を2〜3倍に高める」ことが繰り返し実証されています。
意志力に頼らず、「状況（if）」が自動的に「行動（then）」を引き出す仕組みを作ります。

---

### 1-4. アイデンティティの書き換え ― 「なる」から「である」へ

習慣形成の研究者**BJ・フォッグ（スタンフォード大学）**の知見では、行動変容の最も効果的な方法は「アイデンティティの変容」だと示されています。

「毎日英単語を50個覚えよう（行動目標）」より、
「私は英語を武器にする受験生だ（アイデンティティ）」と自己定義した人のほうが、行動が持続します。

JUKEN COACHでは毎セッションの最後に必ず確認します。

**「今週、志望大学の合格者として行動できた瞬間はありましたか？」**

この問いは、生徒に「自分はもうその資質を持った人間である」という認識を少しずつ育てます。
大きな変化を一気に起こそうとするのではなく、小さな証拠を毎週積み重ねることで、潜在意識レベルで「自分は合格できる人間だ」という自己像が形成されていきます。

---

### 1-5. 自己効力感の構築 ― バンデューラの理論を実践に

**アルバート・バンデューラ（1977）**の自己効力感理論によると、「自分にはできる」という信念は4つの方法で育まれます。

| 方法 | 受験コーチングでの実践 |
|---|---|
| **達成体験**（最強） | 毎週「できた小さなこと」を必ず言語化させる |
| **代理体験** | からしかし・コーチAの合格体験を具体的に共有する |
| **言語的説得** | 「あなたにはこの根拠で可能性がある」を具体的に伝える |
| **生理的覚醒の解釈** | 試験前の緊張を「やる気のサイン」と解釈するよう訓練する |

## PILLAR 2｜志望校戦略設計
### ― 合格から逆算した「地図」を描く

---

### 2-1. 志望校の本質的な分析

感情論や偏差値だけで志望校を決めている受験生がほとんどです。
JUKEN COACHでは、志望校を「攻略すべきゲーム」として分析します。

**志望校分析シートで確認すること：**

```
① 合格に必要な得点率（共通テスト + 二次試験）
② 二次試験の科目別配点比率
③ 過去問から見えるキャラクター
   （「深さ」か「広さ」か、「処理速度」か「論述力」か）
④ 合格者最低点 vs 自分の現在地のギャップ
⑤ 「どの科目で何点取るか」の得点配分計画
```

**東大と京大の違いの例（重要）：**

| 項目 | 東大 | 京大 |
|---|---|---|
| 入試の性格 | 正確さ・処理速度・広さ | 深さ・独創性・論述力 |
| 英語 | 長文読解 + 英作文（スピード重視） | 和訳・英訳（精度重視） |
| 数学 | 全問解こうとしない、部分点戦略が有効 | 論述の過程が採点対象、答えだけ合っても失点 |
| 合格戦略 | 苦手科目を作らない「バランス型」 | 強みの科目で大きく稼ぐ「特化型」も有効 |

---

### 2-2. 逆算ロードマップの設計

「今の偏差値」から「合格」への道のりを、月単位で設計します。

```
【例：高2秋スタート、東大理系志望の場合】

今：英語 偏差値55 / 数学 偏差値60 / 理科 未完成
目標：英語 70 / 数学 68 / 理科 65（合格ラインの目安）

高2冬（3ヶ月）：英語基礎固め（1冊完璧化）+ 数学演習継続
高3春（3ヶ月）：英語長文演習 + 数学応用 + 理科基礎スタート
高3夏（3ヶ月）：過去問演習開始 + 弱点の集中補強
高3秋（3ヶ月）：共通テスト対策 + 二次演習
高3冬（2ヶ月）：二次対策に集中・共通テスト仕上げ
```

このロードマップは毎月のセッションで模試データをもとに修正します。
「計画通りにいかないこと」を前提に設計するのがポイントです。

## PILLAR 3｜実行管理システム
### ― やり切る仕組みを外側に作る

---

### 3-1. 参考書ルート ― 情報の迷子を終わらせる

「何を使えばいいかわからない」は受験生が最も時間を無駄にする問題です。
JUKEN COACHでは入会時に科目別の参考書ルートを確定し、「これ以外はやらなくていい」と明言します。

**参考書選定の原則：**
1. **1冊完璧主義** ― 3冊を30%ずつより、1冊を100%のほうが合格に近い
2. **レベルの正確な把握** ― 今の実力より少し上の参考書を選ぶ（高すぎると挫折、低すぎると時間の無駄）
3. **ゴール設定** ― 「この参考書を終えたら何ができるようになるか」を先に確認する

**科目別参考書ルート例（東大理系）：**

| 科目 | レベル1（基礎） | レベル2（標準） | レベル3（応用） |
|---|---|---|---|
| 英語 | システム英単語 + 基礎英文解釈100 | ポレポレ + 英語長文問題精講 | 東大過去問 |
| 数学 | 基礎問題精講 | 標準問題精講 | 東大過去問 + 鉄則 |
| 物理 | 物理のエッセンス | 名問の森 | 東大過去問 |
| 化学 | 化学の新研究（参照）+ 重問 | 重問A問題完璧化 | 東大過去問 |

---

### 3-2. 週次PDCAサイクル

毎週のセッションは以下の構造で行います。

```
【毎週のセッション構造（60分）】

最初の10分：先週の振り返り
 ・何ができたか（できたことを先に確認する）
 ・何ができなかったか、なぜか
 ・勉強ログ（時間・科目）の確認

中間の30分：課題の深掘りと解決
 ・理解できていない問題の解説
 ・つまずいている単元の原因特定
 ・次週の計画修正

最後の20分：次週の計画設定
 ・具体的な行動目標（「英語を頑張る」ではなく「単語帳を毎日20分・問題集3ページ」）
 ・if-thenプランの設定（障害への対処を先に決める）
 ・今週の「自分への約束」を1つ言語化する
```

---

### 3-3. 学習ログの管理

感覚で「今週は頑張った」と言える受験生は多いですが、データで示せる受験生は少ない。
JUKEN COACHでは **Studyplus** または **Notion** での学習ログを必須としています。

記録するもの：
- 科目別勉強時間（毎日）
- 使用した参考書・到達ページ
- その日「できなかった問題」のメモ（翌日の最初に復習）

週次で科目バランスを確認し、偏りがあれば翌週の計画に反映します。

## まとめ ― JUKEN COACHが提供するもの

| 一般的な受験指導 | JUKEN COACH |
|---|---|
| 勉強法・参考書の情報提供 | 心理 × 戦略 × 実行の3層を設計 |
| 「何をすべきか」を教える | 「なぜするか」から設計し直す |
| 生徒が受け身になる | 生徒が自分で動く「自走状態」を目指す |
| 先生が主役 | 生徒が主役、コーチは設計者 |
| 単発のアドバイス | 毎週のPDCAで継続的に改善 |

**私たちが最終的に目指す生徒像：**
> 受験が終わっても、自分で目標を設定し、計画を立て、振り返り、修正できる人間。
> それがJUKEN COACHの卒業生です。
